# ADAPT.AI

ADAPT.AI is a personalised AI tutor that adapts learning paths, difficulty, explanations, and practice based on learner performance.

## Problem Statement

PS-03 – Personalised AI Tutor for Learning AI

Most AI learning platforms use the same content, pace, and sequence for every learner. ADAPT.AI identifies what the learner already knows, detects weak areas, and continuously adapts the learning journey.

## Key Features

- Adaptive Diagnostic Test
- AI Knowledge Map
- Personalised Learning Roadmap
- Adaptive Tutor
- Explain Differently modes
- Concept Mastery Tracking
- Repeated Error Detection
- Automatic Micro-Lesson Insertion
- Dynamic Roadmap Adaptation
- Progress Dashboard

## Demo Flow

Diagnostic  
→ Knowledge Map  
→ Personalised Roadmap  
→ Adaptive Tutor  
→ Practice Questions  
→ Mastery Update  
→ Weakness Detection  
→ Micro-Lesson Insertion  
→ Progress Dashboard
